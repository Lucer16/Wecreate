# WeCreate | Servicios Profesionales de Diseño Web

¡Bienvenido a **WeCreate**!

Este proyecto corresponde al sitio web oficial de **WeCreate**, una página diseñada para presentar de forma clara y profesional los servicios de diseño y desarrollo web que ofrezco. En ella los visitantes pueden conocer mi experiencia, consultar los precios de los servicios disponibles y encontrar los diferentes medios de contacto para solicitar una cotización o iniciar un proyecto.

La aplicación fue desarrollada utilizando **HTML, Tailwind CSS y JavaScript**, ofreciendo una interfaz moderna, responsiva y optimizada para una excelente experiencia de usuario en dispositivos móviles, tabletas y computadoras.

## 🚀 Objetivo del Proyecto

Este proyecto tiene como objetivo:

- Presentar los servicios profesionales ofrecidos por **WeCreate**.
- Mostrar mi experiencia en el área de diseño y desarrollo web.
- Publicar los precios de los diferentes servicios para facilitar la toma de decisiones de los clientes.
- Proporcionar información de contacto para consultas, cotizaciones y contratación.
- Aplicar buenas prácticas de desarrollo Frontend mediante una interfaz moderna, rápida y completamente responsiva.

## ✨ Características

- 🎨 Diseño moderno y atractivo.
- 📱 Diseño 100% responsivo.
- 💼 Sección de servicios profesionales.
- 💲 Catálogo de precios.
